# voting-eligibility-cpp
A simple C++ program that checks whether a person is eligible to vote based on age using if-else condition.


# Voting Eligibility Checker in C++

## 📌 Description
This program checks whether a person is eligible to vote based on their age.

## 🚀 How It Works
- User enters age.
- If age is 18 or above → Eligible to vote.
- Otherwise → Not eligible.

## 📥 Input Example
```text
20
```

## 📤 Output Example
```text
Eligible to vote
```

## 🛠️ Concepts Used
- C++
- Input/Output (cin, cout)
- If-Else Condition
- Comparison Operator (>=)

## 🎯 Learning Outcome
- Conditional logic
- User input handling
- Basic decision making in C++
